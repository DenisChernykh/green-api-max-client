# MAX × GREEN-API — клиент переписки

React-приложение для текстовой переписки в MAX через GREEN-API.

## Возможности

- Подключение инстанса через параметры API.
- Создание чата, отправка текста и получение входящих сообщений.
- Валидация форм, типизированные ответы API и управление серверным состоянием.

## Инженерные акценты

- Интеграция интерфейса с внешним messaging API.
- Разделение FSD-слоёв, форм и пользовательских операций.
- Обработка входящих событий и проверка пользовательских сценариев.

## Стек

React, TypeScript, TanStack Query, Tailwind CSS, Vite, Vitest.
